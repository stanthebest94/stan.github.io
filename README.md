# Chukwu Stanley Emeka — GitHub Portfolio

A fast, responsive, dependency-free personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — website structure and content
- `style.css` — responsive design
- `script.js` — mobile navigation and dynamic year
- `.nojekyll` — prevents unnecessary Jekyll processing

## Before publishing

Open `index.html` and replace:

- `YOUR-GITHUB-USERNAME`
- `YOUR-LINKEDIN-USERNAME`
- `YOUR-EMAIL@example.com`
- `YOUR-UPWORK-ID`

You can also update the project descriptions, certifications and career details.

## GitHub Pages

Recommended repository name for a personal site:

`YOUR-GITHUB-USERNAME.github.io`

Push the files to the `main` branch, then go to:

Repository → Settings → Pages

Choose:

- Source: GitHub Actions

GitHub Pages can publish this static site directly from the repository.

## Local preview

You can simply open `index.html` in a browser.

For a local server, if Python is installed:

`python -m http.server 8000`

Then visit:

`http://localhost:8000`

## Notes

This website intentionally uses no external frameworks or npm packages, so it can be deployed immediately as a static GitHub Pages site.
